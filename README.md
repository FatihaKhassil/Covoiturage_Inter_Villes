# 🚗 Application de Covoiturage Inter-Villes

## Description
Application web permettant de mettre en relation des **conducteurs** et des **passagers**
afin de partager des trajets entre villes pour les étudiants et les travailleurs.

---

## Objectif
Mettre en relation conducteurs et passagers pour faciliter le covoiturage
inter-villes à moindre coût.

---

## 👥 Acteurs
- 🚘 Conducteur  
- 🧍 Passager  
- 🛠️ Administrateur  

---

## ⚙️ Fonctionnalités

###  Fonctionnalités principales
- Gestion des profils utilisateurs  
- Publication d’un trajet (ville de départ, ville d’arrivée, heure, prix)  
- Réservation de place par un passager  
- Système d’évaluations et d’avis  
- Notifications de confirmation  

---

##  Technologies utilisées
- Java Servlets / JSP  
- Architecture MVC  
- MySQL  
- WebSockets (pour notifications en temps réel)  

---

##  Installation et Exécution

### 📌 Prérequis
- Java JDK  
- Apache Tomcat  
- MySQL  

---

### 📌Configurer le fichier de connexion avec DB
